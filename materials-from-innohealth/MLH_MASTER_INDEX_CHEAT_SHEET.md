## How to Use This Index

Daily method:
1. Read one sheet deeply.
2. Explain it out loud in your own words.
3. Do one coding or analysis exercise from that sheet.
4. Practice 3 related interview questions.
5. Log weak spots and revisit next day.

## Minimum Mastery Checklist

You are ready when you can do all of this clearly:

1. Explain architecture and component composition.
2. Explain TypeScript choices and safety benefits.
3. Explain styling approach and design-token consistency.
4. Explain routing behavior in dev and production.
5. Explain forms end-to-end including async submission.
6. Explain animation strategy and tradeoffs.
7. Explain deployment pipeline from source to hosted app.
8. Explain one weakness and one realistic improvement plan.
